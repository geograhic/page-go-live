站点简介

Endril 在线网页站（html.endril.com，项目代号 page-go-live）是一个免费的网页工具托管与分享平台。无论你写好了一个本地网页工具、还是想把自己做的页面分享给更多人，都可以在这里一键发布上线——提交内容经审核通过后即自动出现在首页，让更多人看到、用到你的作品。

站内工具覆盖 GIS 地理信息、KML/SHP 坐标转换、地图可视化、开发者效率等多个方向；我们更希望你把自己的网页工具也带来这里，与社区共享。

项目目标

  • 一键上线：把本地网页工具 / 页面轻松转为在线可访问的链接；
  • 自动收录：工具上传后自动出现在首页，无需手动维护工具列表；
  • 开放投稿：任何人都能提交网页工具，审核通过后自动上线，并记入贡献者名单。

创建背景

很多实用的小工具、小页面只躺在开发者的电脑里——要分享就得自己买服务器、配域名、做部署，门槛不低。page-go-live 想把这些步骤压到最低：你只需要把做好的网页交上来，剩下的托管、索引、上线由我们来做。让「做出一个网页工具」和「让全世界用上它」之间的距离，缩短到一次提交。

技术理念

  • 纯静态托管：基于 GitHub Pages，无服务器端运行时，打开即用；
  • 浏览器端运行：工具的计算与文件处理在访客本地完成，不上传用户数据；
  • 开源透明：源代码托管于 GitHub，欢迎审查与贡献；
  • 免费共享：平台与站内工具均免费开放，不设付费墙；
  • 自动收录：CI 监听 tools/** 变更，自动重生成清单并部署，新工具推送即上线。

隐私与数据

我们坚持「工具在浏览器里跑、数据不离开本地」的原则。你上传到工具中的文件仅在本机浏览器内存中处理，关闭页面即被丢弃。详细的 Cookie 与数据处理方式请参阅 隐私政策。

贡献与提交

本站欢迎社区贡献。如果你有想分享的网页工具，可通过首页「提交你的网页工具」卡片或 GitHub Issue 提交，审核通过后将在本站上线并记入贡献者名单；有写权限的维护者也可直接在 tools/ 下新增工具目录并推送 main 分支，自动上线。
