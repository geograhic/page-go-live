隐私政策

最后更新：2026 年 8 月 27 日  |  生效日期：2026 年 8 月 27 日

Endril 在线网页站（以下简称「本站」，域名 html.endril.com）由 Endril（李义洵）运营。本站是一个纯静态网页工具集合，专注 GIS 地理信息、KML/SHP 坐标转换、地图可视化与开发者效率工具。我们高度重视您的隐私，本政策说明我们在您访问本站时如何处理数据。

1. 我们收集的信息

本站所有网页工具（包括 KML 合并/分割、KML 按位置分割、SHP 转 KML 等）均为纯浏览器端运行，您的数据文件不会上传到我们的服务器。您上传到工具中的文件（如 .kml、.shp、.csv 等）仅在您本地浏览器内存中处理，关闭页面即被丢弃。

我们不要求注册账户，不收集姓名、邮箱等个人身份信息。

2. 自动收集的技术数据

由于本站托管于 GitHub Pages 并经 Cloudflare 提供 CDN，基础设施提供方可能自动记录下列非个人化数据：

  • 访问时间、IP 地址（可能被 CDN 截断或匿名化）；
  • 浏览器类型、操作系统、访问来源 URL；
  • 请求的资源路径与状态码。

这些日志仅用于安全防护、流量统计与性能优化，不与个人身份关联。

3. Cookie 与本地存储

本站首页与各工具页可能使用浏览器的 localStorage / sessionStorage 保存用户偏好（如语言选择、工具设置、最近使用记录），这些数据仅存储在您的浏览器中，不发送给我们。本站不使用跟踪类 Cookie。

4. 第三方服务

本站页面可能加载以下第三方资源，这些服务方可能根据其自身隐私政策处理数据：

  • GitHub Pages：本站托管服务，可能记录访问日志；
  • Cloudflare CDN：内容分发与安全防护；
  • OpenStreetMap / Leaflet：地图底图瓦片，当您使用含地图的工具时，地图提供方会收到瓦片请求；
  • cdnjs / unpkg / jsdelivr：JavaScript 与 CSS 库的 CDN 分发。

若这些服务收集了您的数据，受其各自隐私政策约束，建议您查阅对应方的政策。

5. 第三方广告

本站拟接入第三方广告服务（如 Google AdSense）。若接入，广告服务可能使用 Cookie 收集您设备的信息（如 IP、浏览器特征）以展示相关广告并衡量广告效果。您可通过浏览器设置管理或禁用 Cookie，或访问广告服务商的退出页面。Google 的隐私政策与个性化广告设置见 Google 广告隐私政策。

6. 数据安全

由于本站不存储用户上传数据，不存在数据泄露风险。基础设施日志由 GitHub / Cloudflare 按其安全标准保护。

7. 您的权利

对于基础设施方可能持有的日志，您可依《个人信息保护法》《通用数据保护条例（GDPR）》《加州消费者隐私法（CCPA）》等向服务方主张访问、更正、删除等权利。本站不直接持有您的个人数据，故无需向本站主张。

8. 儿童隐私

本站面向开发者与地理信息从业人员，不针对 13 岁以下儿童。若您是监护人并发现未成年人提供了不应提供的信息，请联系我们删除。

9. 政策变更

本政策可能随业务演进更新，更新后将在本页顶部标注新日期。重大变更会通过本页公告。

10. 联系我们

如对本政策有任何疑问，请通过 联系我们 页面提供的方式与我们沟通。
