隐私政策

最后更新：2026 年 8 月 27 日  |  生效日期：2026 年 8 月 27 日

Endril 在线网页站（以下简称「本站」，域名 html.endril.com，项目代号 page-go-live）由 Endril（李义洵）运营。本站是一个免费的网页工具托管与分享平台：你提交的网页工具或页面经审核通过后会自动上线，供所有人使用。我们高度重视你的隐私，本政策说明你访问本站及使用站内工具时我们如何处理数据。

1. 我们收集的信息

本站所有网页工具（包括 KML 合并/分割、KML 按位置分割、SHP 转 KML 等）均为纯浏览器端运行，你上传到工具中的文件不会上传到我们的服务器。文件（如 .kml、.shp、.csv 等）仅在你的本地浏览器内存中处理，关闭页面即被丢弃。

我们不要求注册账户，不收集姓名、邮箱等个人身份信息。通过投稿入口提交工具时，你提供的「工具地址」「作者署名」「作者主页」等仅用于展示与归因，按 GitHub 仓库的公开协作流程处理，本身不进入本站数据库。

2. 自动收集的技术数据

由于本站托管于 GitHub Pages 并经 Cloudflare 提供 CDN，基础设施提供方可能自动记录下列非个人化数据：

  • 访问时间、IP 地址（可能被 CDN 截断或匿名化）；
  • 浏览器类型、操作系统、访问来源 URL；
  • 请求的资源路径与状态码。

这些日志仅用于安全防护、流量统计与性能优化，不与个人身份关联。

3. Cookie 与本地存储

本站首页与各工具页可能使用浏览器的 localStorage / sessionStorage 保存用户偏好（如语言选择、工具设置、最近使用记录），这些数据仅存储在你的浏览器中，不发送给我们。

在你通过页面底部的同意横幅点击「接受」后，本站会加载 Google AdSense 广告服务，该服务可能在你的设备上设置广告相关 Cookie（如用于个性化广告投放与效果衡量的 NID、IDE 等），以展示与您更相关的广告。若你选择「拒绝」或未作出选择，则不会加载广告脚本，也不会设置此类 Cookie。你可以随时点击右下角「Cookie 设置」撤回或更改同意（该按钮可自由拖动到屏幕任意位置）。

4. 第三方服务

本站页面可能加载以下第三方资源，这些服务方可能根据其自身隐私政策处理数据：

  • GitHub Pages：本站托管服务，可能记录访问日志；
  • Cloudflare CDN：内容分发与安全防护；
  • OpenStreetMap / Leaflet：地图底图瓦片，当你使用含地图的工具时，地图提供方会收到瓦片请求；
  • cdnjs / unpkg / jsdelivr：JavaScript 与 CSS 库的 CDN 分发。

若这些服务收集了你的数据，受其各自隐私政策约束，建议你查阅对应方的政策。

5. 第三方广告（Google AdSense）

本站使用 Google AdSense 在首页与各工具页展示广告。AdSense 可能使用 Cookie 及类似技术收集你设备的信息（如 IP 地址、浏览器与设备特征、大致地理位置）以投放个性化或非个性化广告，并衡量广告效果。AdSense 仅在你同意（点击「接受」）后加载；你拒绝后将不展示个性化广告，也不会加载广告脚本。

你可通过以下方式管理广告偏好或退出个性化广告：Google 广告设置（ads.google.com/settings/ads）、Google 广告技术与隐私政策（policies.google.com/technologies/ads），或通过浏览器设置禁用 Cookie。对于欧盟（GDPR）与加利福尼亚州（CCPA）用户，你有权拒绝广告 Cookie 且不影响本站工具的正常使用。

6. 数据安全

由于本站不存储用户上传数据，不存在数据泄露风险。基础设施日志由 GitHub / Cloudflare 按其安全标准保护。

7. 你的权利

对于基础设施方可能持有的日志，你可依《个人信息保护法》《通用数据保护条例（GDPR）》《加州消费者隐私法（CCPA）》等向服务方主张访问、更正、删除等权利。本站不直接持有你的个人数据，故无需向本站主张。

8. 儿童隐私

本站面向开发者与网页工具使用者，不针对 13 岁以下儿童。若你是监护人并发现未成年人提供了不应提供的信息，请联系我们删除。

9. 政策变更

本政策可能随业务演进更新，更新后将在本页顶部标注新日期。重大变更会通过本页公告。

10. 联系我们

如对本政策有任何疑问，请通过 联系我们 页面提供的方式与我们沟通。
